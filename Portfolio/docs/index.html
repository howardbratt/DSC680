Featured project · Advanced Uses of Generative AI

Healthcare Data Mapping Assistant

I built a Streamlit prototype that recommends where incoming demographic fields belong in a shared healthcare schema. It proposes a target for clear cases and sends ambiguous cases to an analyst. For example, it mapped a birth date to date_of_birth and flagged a combined full-name field for review.
